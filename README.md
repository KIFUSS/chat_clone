# Telegram Clone (Учебный Full-Stack Мессенджер)

Это пет-проект по созданию клона мессенджера Telegram. Пишется в целях обучения, изучения работы с веб-сокетами, авторизацией и правильной структуризацией кода на бэкенде и фронтенде. 

Проект в процессе разработки, сделана базовая рабочая часть, впереди еще много доработок.

---

## 🛠 Что уже сделано и работает

*   **Авторизация (JWT + OTP):** Вход по номеру телефона. Генерируется временный 5-значный код (пока симуляция в консоль сервера), после проверки выдаются Access/Refresh токены.
*   **Чат на сокетах (Socket.io):** Реализована отправка и получение сообщений в реальном времени без постоянных HTTP-запросов к серверу.
*   **Двухуровневый поиск чатов:** Если в инпут вводится текст, поиск идет локально по текущим чатам юзера на фронтенде. Если вводится полный номер телефона — уходит запрос на бэкенд через сокеты для поиска глобального пользователя в базе.
*   **Разделение архитектуры на бэкенде:** Код разнесен по слоям (роуты отдельно, контроллеры отдельно, обработчики сокет-событий в папке `socket/`), чтобы не захламлять точку входа сервера.

---

## 💻 Технологический стек

*   **Фронтенд:** React 19, TypeScript, Tailwind CSS v4, Socket.io-client. Бизнес-логика (поиск, чаты) вынесена в кастомные хуки (`useSearch`, `useChat`).
*   **Бэкенд:** Node.js, Express, Socket.io, MongoDB / Mongoose (база данных для пользователей и сообщений).

## 📂 Структура проекта

```text
chat_clone/
├── client/             # Фронтенд-приложение (Vite + React + TS)
│   └── src/
│       ├── components/ # Визуальные компоненты интерфейса
│       ├── pages/      # Страницы (Авторизация, Чат)
│       └── hooks/      # Кастомные хуки с логикой (useSearch, useChat)
└── server/             # Бэкенд-приложение (Node.js + Express + Socket.io)
    ├── config/         # Настройки базы данных и CORS
    ├── controllers/    # Логика HTTP-запросов (авторизация, коды)
    ├── routes/         # HTTP маршруты (/api/auth)
    ├── socket/         # Логика веб-сокетов (поиск юзеров, отправка сообщений)
    ├── models/         # Схемы таблиц базы данных Mongoose (User, Message)
    ├── app.js          # Сборка и настройка Express
    └── server.js       # Точка запуска всего бэкенда и сокетов
```

## ⚙️ Как запустить локально

### 1. Клонировать репозиторий
```bash
git clone https://github.com
cd chat_clone
```

### 2. Запуск бэкенда (Server)
```bash
cd server
npm install
```
Создай `.env` файл в папке `server` и укажи свои данные:
```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/telegram_db
JWT_ACCESS_SECRET=your_secret_key
JWT_REFRESH_SECRET=your_refresh_key
CLIENT_URL=http://localhost:5173
```
Запуск сервера:
```bash
npm run dev
```

### 3. Запуск фронтенда (Client)
Открой второе окно терминала:
```bash
cd client
npm install
npm run dev
